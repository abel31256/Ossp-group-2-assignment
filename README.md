# Project Overview

This assignment explores the modern computer hardware ecosystem and supply chain relationship between four major technology companies:

* AMD – Processor Manufacturer
* HP Inc. – Computer System Manufacturer (OEM/CSM)
* Nanya Technology – DRAM Memory Supplier
* Kioxia – NAND Flash / SSD Supplier

The report explains how these companies work together to build modern AI-enabled computing systems such as laptops and desktops.
